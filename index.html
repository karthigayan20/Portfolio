How I work

The same four moves on every project
01

Find the decision first

Before touching data I write down the decision it should change. A dashboard with no decision attached is a report nobody opens twice.

02

Instrument the funnel

Define the steps, agree the definitions, then measure every step in the same query so the numbers reconcile when someone challenges them.

03

Size the gap in money

Every finding gets converted into customers, MRR or hours saved, with the assumptions written next to it so a stakeholder can argue with the assumption, not the arithmetic.

04

Automate what repeats

If a report or a workflow runs more than twice, it gets automated — that is where the 40% manual-effort reduction at Vendasta came from.
